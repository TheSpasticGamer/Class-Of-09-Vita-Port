About

This project brings Class of '09 to the PlayStation Vita.

The Vita build uses a small installer VPK, while the main game content is kept separate. The installer alone does not contain everything required to run the game.

Features

Playable on PlayStation Vita

Vita-native installer

Vita-friendly controls

Vita-adapted interface and presentation

Small installer VPK

Main game content stored separately

Ongoing compatibility fixes and improvements

Requirements

You will need:

A modded PlayStation Vita capable of installing homebrew

VitaShell

ClassOf09-Native-0.28-Installer.vpk

The separate Class of '09 content files

Installation

Download the latest installer VPK:
ClassOf09-Native-0.28-Installer.vpk

Download the required separate game content.

Transfer the installer VPK and content files to your PlayStation Vita using VitaShell, USB, FTP, or another supported transfer method.

Open VitaShell.

Locate and install:
ClassOf09-Native-0.28-Installer.vpk

Copy or extract the separate game content to the location specified with the content package.

Keep the supplied folder structure intact. Do not move individual game files unless the installation instructions specifically tell you to.

Return to the Vita home screen and launch Class of '09.

Important

The VPK is intentionally small and does not contain the full game content.

You need both:

The installer VPK

The separate game content

Installing only the VPK will not provide a complete playable installation.
